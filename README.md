Higher or Lower (Instagram Edition)

This is a small Python terminal game where you compare two Instagram accounts and try to guess which one has more followers.

It’s based on the “Higher or Lower” style games.

How to play

You’ll see two accounts (A and B). Each one has a name, description, and country.

Your job is simple:
- Type 'A' or 'B'
- Pick who you think has more followers

If you’re right, your score goes up and the game continues.
If you’re wrong, the game ends and your final score is shown.


Features

- Random account comparisons every round  
- Score system that tracks how far you get  
- Prevents the same account from being compared against itself  
- Keeps the game going with the winning account  
- Input checking so only A or B is accepted  
- Option to play again after you lose
